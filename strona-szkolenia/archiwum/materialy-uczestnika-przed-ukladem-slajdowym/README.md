# Materiały archiwalne

Zawartość tego katalogu pochodzi z poprzedniego modelu materiałów: krótkich
kart modułów, rozwiniętej teorii i zadań. Jest zachowana jako zapis historii
redakcyjnej, ale nie jest aktywną treścią strony i nie uczestniczy w budowaniu
jej kolekcji.

Aktywne slajdy znajdują się w `../../src/content/moduly/`. Zadania i pogłębione
materiały uczestnika są odrębnymi etapami, które mogą powstać później.
